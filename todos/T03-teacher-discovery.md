# T03 — Teacher discovery

**Status:** done

## Goal

Let students discover, search, filter, compare, and open teacher profiles.

## Implementation steps

- Add subject constants and teacher profile query filters.
- Add paginated teacher discovery API and service.
- Add responsive teacher cards with rating, experience, VIP, and availability
  summaries.
- Add search and filters for subject, experience, rating, availability, and
  verification.
- Add teacher profile detail route.
- Add rating and review fields after the immutable rating system lands in T05.

## Acceptance criteria

- Student sees only discoverable teacher profiles.
- Search and filters work together and are paginated.
- A teacher with no reviews displays “No ratings yet”.
